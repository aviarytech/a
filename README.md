# a

Shared agent instructions (AGENTS.md) for Aviary projects.

## Guidelines for editing AGENTS.md
- Write down what an agent would get wrong without being told; skip what it can infer from code.
- Prefer concrete commands and rules over vague advice ("write clean code").
- Keep it tight (~100–300 lines); move detail into linked docs or nested AGENTS.md files.
- Treat it like code: review changes in PRs and delete stale entries.
